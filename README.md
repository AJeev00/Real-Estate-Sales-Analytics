# PropPulse — Real Estate Sales Analytics

A Streamlit dashboard for exploring a real-estate sales lead funnel, channel performance, monthly lead trends and booked value.

## Features
- Lead funnel and conversion KPIs
- Channel-level lead and booking analysis
- Monthly lead and booked-value trends
- CRM-style filters
- Downloadable filtered lead records

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Data
The included lead dataset is synthetic and for demonstration only. It does not represent real customers or any company's CRM data.

## Deployment
Deploy `app.py` on [Streamlit Community Cloud](https://share.streamlit.io/).
